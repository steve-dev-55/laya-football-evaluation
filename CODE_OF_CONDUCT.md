# Code de conduite

## Engagement

Dans l'intérêt d'un environnement ouvert et accueillant, nous nous engageons
en tant que contributeurs et responsables à faire de la participation à ce
projet une expérience sans harcèlement pour tout le monde, quel que soit
l'âge, le corps, la taille, le handicap, l'ethnicité, les caractéristiques
sexuelles, l'identité ou l'expression de genre, le niveau d'expérience,
l'éducation, le statut socio-économique, la nationalité, l'apparence
personnelle, la race, la religion ou l'identité et l'orientation sexuelles.

## Normes

Comportements attendus :

- utiliser un langage accueillant et inclusif ;
- respecter les points de vue et expériences différents ;
- accepter les critiques constructives ;
- se concentrer sur ce qui est le mieux pour la communauté scientifique ;
- faire preuve d'empathie envers les autres membres.

Comportements inacceptables :

- harcèlement, commentaires ou images sexualisés, trolling ;
- commentaires offensants ou désobligeants, attaques personnelles ou
  politiques ;
- publication d'informations privées d'autrui sans consentement explicite ;
- toute conduite raisonnablement considérée comme inappropriée dans un
  cadre scientifique professionnel.

## Responsabilités

Les mainteneurs clarifient et appliquent les normes de comportement et
prendront des mesures correctives proportionnées pour tout comportement
jugé inapproprié, menaçant, offensant ou nuisible.

## Portée

Ce code s'applique à tous les espaces du projet (issues, PR, discussions) et
lorsqu'un individu représente officiellement le projet en public.

## Signalement

Les comportements abusifs peuvent être signalés en ouvrant une issue
confidentielle ou en contactant les mainteneurs via les coordonnées du
dépôt. Toutes les plaintes seront examinées et traitées avec diligence.
